# Time Book Installation & Download

## 📱 Install on Your Phone

### For Android

#### Option 1: Direct APK Download
1. Download: [Time Book.apk](https://github.com/chikllnylmgok1234-coder/Time-Book/releases/download/v1.0.0/TimeBook-1.0.0.apk)
2. Enable unknown sources: Settings → Security → Unknown Sources
3. Open downloaded APK file
4. Tap "Install"
5. Launch "Time Book"

#### Option 2: Google Play Store
1. Open Google Play Store
2. Search for "Time Book"
3. Tap "Install"
4. Open app after installation

#### Option 3: Build from Source
```bash
git clone https://github.com/chikllnylmgok1234-coder/Time-Book.git
cd Time-Book/mobile
npm install
npm run android
```

### For iOS

#### Option 1: App Store
1. Open App Store
2. Search for "Time Book"
3. Tap "Get"
4. Authenticate with Face ID / Touch ID
5. Wait for installation
6. Launch "Time Book"

#### Option 2: TestFlight (Beta)
1. Install TestFlight app
2. Open link: [TestFlight Link](https://testflight.apple.com/...)
3. Tap "Install"
4. Launch "Time Book"

#### Option 3: Build from Source
```bash
git clone https://github.com/chikllnylmgok1234-coder/Time-Book.git
cd Time-Book/mobile
npm install
npm run ios
```

## 🚀 Quick Start After Installation

1. **Open Time Book**
   - App will show splash screen
   - Wait for 2 seconds

2. **View Onboarding**
   - See 3 welcome screens
   - Tap "Get Started"

3. **Enter Phone Number**
   - Select country
   - Enter 10-digit mobile number
   - Tap "Send OTP"

4. **Verify OTP**
   - Enter 6-digit code (received via SMS)
   - Tap "Verify"

5. **Create Profile**
   - Enter Full Name
   - Create Username
   - Set Password (8+ characters)
   - Tap "Create Profile"

6. **Start Using Time Book**
   - Add contacts
   - Send your first message
   - Make calls
   - Share status

## 🆘 Having Issues?

### App Won't Install
- Check 100 MB free storage
- Enable unknown sources (Android)
- Retry download
- Contact support: support@timebook.app

### Can't Receive OTP
- Check phone number is correct
- Check SMS is enabled on device
- Try requesting OTP again
- Check spam folder
- Try a different phone number

### App Crashes on Startup
- Check Android/iOS version compatibility
- Uninstall and reinstall app
- Clear app cache
- Restart phone
- Update OS

### Can't Connect to Backend
- Check internet connection
- Check if backend is running
- Verify API URL in settings
- Try WiFi or mobile data
